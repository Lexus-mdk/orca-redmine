# Redmine для Orca

Панель в правом сайдбаре Orca с задачами Redmine, назначенными на вас.

- Открытые задачи, сгруппированные по статусам, с поиском по номеру и тексту. Enter в поиске находит любую задачу по номеру, даже если она не ваша.
- Порядок групп — как статусы идут в Redmine; кнопка «Порядок статусов» в шапке панели меняет его стрелками, «Как в Redmine» возвращает исходный.
- Карточка задачи: статус, приоритет, автор, описание, подзадачи, комментарии, ссылка в Redmine.
- **«Сменить статус»** в карточке: только переходы, которые workflow Redmine разрешает вашей роли, и необязательный комментарий. Списка разрешённых переходов Redmine до 5.0 не отдаёт — тогда предлагаются все статусы, и если Redmine молча оставил прежний, панель об этом скажет. Закрытая задача уходит из списка.
- **«Взять в работу»** создаёт в проекте новую ветку и worktree задачи (имя по умолчанию — номер задачи), запускает в нём выбранного в настройках агента с первым промптом и открывает этот workspace. Проект — из настройки «Папка проекта», а если она пустая — проект открытого сейчас workspace. Setup-скрипт проекта выполняется, как настроено в Orca.
- Если у задачи уже есть worktree — созданный плагином или worktree проекта с номером задачи в имени папки или ветки, — кнопка называется «Продолжить» и запускает в нём агента со вторым промптом.
- Фоновая проверка каждые 5 минут, уведомление о новых задачах, счётчик в статус-баре. Нажатие на счётчик обновляет список.

Код не привязан к ОС; проверен на Windows. На Linux нужна ключница (GNOME Keyring или KWallet): без неё Orca не даёт плагинам хранить секреты, и API-ключ не сохранится.

## Установка

Нужна Orca 1.4.261 или новее.

```sh
orca plugin install Lexus-mdk/orca-redmine
```

Orca ставит последнюю версию с тегом `vX.Y.Z` и перед включением показывает, какой доступ просит плагин: он запускает свой код, создаёт worktree и запускает агентов, поэтому без подтверждения не включится. Команда с `--approve <fingerprint>`, которую Orca напечатает, включает его. Обновление — `orca plugin update`.

Можно поставить и из скачанной папки: `orca plugin install /путь/к/orca-redmine`.

## Подключение

При первом открытии панель спрашивает адрес Redmine и API-ключ (Redmine → «Моя учётная запись» → «Ключ доступа к API»). Оба проверяются запросом к `/users/current.json` и сохраняются, только если Redmine их принял. В Redmine должен быть включён REST API (Администрирование → Настройки → API).

Ключ хранится в зашифрованном хранилище секретов плагина (ключница ОС: Windows, macOS Keychain). В панель он не попадает: все запросы к Redmine делает воркер. Сменить адрес или ключ — кнопка с шестерёнкой в шапке панели; пустое поле ключа оставляет прежний.

## Настройки

Settings → Plugins → Redmine:

| Настройка | По умолчанию | |
| --- | --- | --- |
| Разметка текста | Textile | Как в Redmine: Администрирование → Настройки → Общие → Форматирование текста |
| Папка проекта | пусто | Git-проект в Orca, где создаются worktree задач. Пусто — проект открытого workspace; существующие worktree тогда узнаются, только если их создал плагин |
| Агент | Claude Code | Также Codex, OpenCode |
| Промпт: взять в работу | `Возьми в работу задачу Redmine #{id} «{subject}»: {url}. …` | Уходит агенту в новом worktree. `{id}` — номер, `{subject}` — тема, `{url}` — ссылка |
| Промпт: продолжить | `Продолжи работу над задачей Redmine #{id} «{subject}»: {url}.` | Те же подстановки |
| Имя worktree | `{id}` | Имя worktree и ветки |
| Базовая ветка | пусто | От какой ветки создавать; пусто — как решит Orca |
| Пропускать setup-скрипт | нет | |
| Проверять новые задачи, минут | 5 | 0 — не проверять |
| Уведомлять о новых задачах | да | |

Промпт может быть командой агента, например `/task-start {id}` и `/task-continue {id}`.

## Разработка

```sh
orca plugin validate .
orca plugin dev watch .        # грузит папку в Orca, печатает логи и перезагрузки
npx -p typescript tsc -p .     # проверка типов
```

`orca plugin test` и `orca plugin check` в Orca 1.4.257–1.4.261 не работают, если плагин лежит не на том
же диске, что Orca: раннер не находит собственный `orca-runtime.mjs`. Пока это не починили,
гоняйте их на копии в `C:`:

```sh
D="$LOCALAPPDATA/Temp/orca-redmine-test"; rm -rf "$D"; mkdir -p "$D"; cp -r . "$D/"
(cd "$D" && orca plugin test . && orca plugin check .)
```

Устройство: `src/worker.ts` — воркер (Redmine API, кеш, опрос, статус-бар, запуск агента),
`src/panel.tsx` — панель на компонентах Orca, `src/protocol.ts` — контракт между ними.
